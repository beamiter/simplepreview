*simplepreview.txt*  Explicit local web-project preview for Vim9

COMMANDS                                           *simplepreview-commands*

:SimplePreviewStart [argv...]                       *:SimplePreviewStart*
    Explicitly start one foreground project command. Default: npm run dev.
    Uses nearest package.json from current local file, or cwd when unnamed.
    Does not install packages. Arguments follow <f-args>, not shell syntax.
    Trust the project before running its scripts. One session per Vim.

:SimplePreviewOpen [path]                           *:SimplePreviewOpen*
    Explicitly open the first accepted loopback origin in the system browser.
    For a web project, requires a running session. Only localhost,
    127.0.0.1 and [::1], HTTP(S), explicit port 1-65535, optional final /.
    Paths in process output, queries, credentials, external addresses and
    wildcard hosts are rejected. An explicit [path], e.g. /web-index.html, may
    select a page on that same origin. No host/port override is possible.
    Path defaults to g:simplepreview_path or /. Allowed: ASCII letters, digits,
    / . _ ~ -. Reject //, dot segments, percent escapes, spaces, backslashes,
    queries and fragments. Use / explicitly to override a configured path.
    Without an argument in a managed Cursor Canvas buffer, starts that Canvas
    preview if needed and opens the page when ready. See |simplepreview-canvas|.

:SimplePreviewStatus                                *:SimplePreviewStatus*
    Show state, project root, argv, URL, exit code and latest output line.
    Output is bounded and can be lossy under backpressure; not a full log.

:SimplePreviewLogs                                  *:SimplePreviewLogs*
    Open/reuse a read-only scratch window with the latest 200 completed output
    lines, capped at 512 Unicode characters each. Terminal CSI/OSC escapes are
    removed. No project file is written. The tail survives window closure and
    is cleared by the next Start. Undo history is disabled. Closing the log window does not stop service.
    Start from this window can reuse the managed session's project directory.
    Flood backpressure may drop output; this is not a complete build log.

:SimplePreviewRestart                               *:SimplePreviewRestart*
    Explicitly repeat the last launched argv and original project directory.
    Wait for full supervisor cleanup before replacing a running session.
    Repeated requests coalesce. Stop or Vim exit cancels the pending restart;
    Status includes restart_pending. Missing original package.json fails closed
    instead of falling back to an ancestor. Errors appear in status/logs with no
    automatic retries. Does not open the browser. Start is required once first.

:SimplePreviewStop                                  *:SimplePreviewStop*
    Asynchronously stop owned foreground process group (TERM, then KILL).
    Cancels any pending Restart; wait for exited before a different Start. Safe to repeat. Vim exit
    also requests cleanup. Deliberately detached/daemonized children excluded.

CONFIGURATION                                      *simplepreview-config*

    g:simplepreview_root       Exact local project root override (string).
    Explicit roots (also Start's directory argument) must exist as directories
    containing their own package.json. No ancestor fallback is allowed for an
    explicit or remembered root. Automatic file-based upward discovery remains
    available when no root override is supplied.
    g:simplepreview_command    Explicit argv list; default ['npm','run','dev'].
    g:simplepreview_path       Explicit page path for Open; default '/'.
    Example: :SimplePreviewStart pnpm run dev:web
             :SimplePreviewOpen /web-index.html
    Select the project's web command yourself; Electron dev is not a web page.
    simplepreview#Start(argv, root) is the equivalent typed API.
    Relative executable paths resolve against the project, never Vim's cwd.
    Configuration alone runs nothing. Repository content is not executed until
    you issue Start. No repository-specific command configuration is loaded.

REQUIREMENTS AND LIMITS                             *simplepreview-limits*

    Vim9 +job +channel and POSIX Python 3 with waitid/WNOWAIT. Web projects need
    package.json, installed dependencies, and a foreground server. Linux tested; macOS
    browser branch unverified; Windows unsupported. Browser opener is xdg-open
    (Linux) or open (macOS). No automatic dependency installation.

    This opens an external browser, not a rendered Vim split. HMR is supplied
    by your dev server after saves, not unsaved edits. General TSX needs an app.
    No SSH port forwarding, remote server,
    server authentication, or browser-render success detection. A loopback
    server can still redirect a browser elsewhere; use trusted projects.

CURSOR CANVASES                                     *simplepreview-canvas*

    Open a saved ~/.cursor/projects/<workspace>/canvases/<name>.canvas.tsx
    in Vim. With no arguments, Open starts and opens the local preview;
    Start launches the preview without opening a browser. Save and reload
    the browser to refresh. Features requiring the editor (such as publishing
    and agent actions) are available in the native Canvas view.

    Requires Node.js, the installed Cursor runtime, and TypeScript. The
    defaults discover the runtime via cursor on PATH and the compiler in the
    SimpleCC-managed TypeScript installation. To override these locations:
      let g:simplepreview_canvas_runtime = '/path/to/canvas-runtime.esm.js'
      let g:simplepreview_canvas_typescript = '/path/to/typescript.js'

MEDIA                                               *simplepreview-media*

:SimplePreviewImage [literal path]                   *:SimplePreviewImage*
:SimplePreviewVideo [literal path]                   *:SimplePreviewVideo*
    Explicit external ffplay window, NOT inline terminal/Vim playback. Default
    is the current saved local buffer. Spaces are literal; do not shell-quote
    or expand %. For arbitrary paths use simplepreview_media#Preview(kind, path).
    Images: png/jpg/jpeg/webp/bmp. Video: mp4/m4v/mov/mkv/webm/avi.
    Requires ffplay, Python and POSIX plus a graphical display. No installation
    or automatic playback. No package.json required; unsaved edits are ignored.

:SimplePreviewMediaStatus                            *:SimplePreviewMediaStatus*
    Independent media process state, path, kind, external backend, exit code,
    and at most 512 escaped output characters. Running or exit 0 does not
    prove display/decode success. ffplay may return 0 on invalid input.

:SimplePreviewMediaStop                              *:SimplePreviewMediaStop*
    Stop only the managed media process group. Vim exit also cleans it up.
    Wait for stopping to finish before another preview. Web session unaffected.

    Only readable regular local files, resolved symlinks and supported target
    extensions; no URLs, special files, playlists or SVG. Absolute argv paths,
    no shell or desktop file associations. Demuxer/protocol allowlists block
    playlist/network inputs; MOV external references stay disabled by default.
    This is not a decoder sandbox or resource limit. Use trusted files and
    updated FFmpeg. Linux synthetic decoding tested using SDL dummy, not a
    visible window/audio or four-terminal end-to-end test. macOS unverified.
